# Literature Survey

## Project

**AI-Based Predictive Auto-Scaling and Resource Optimization for Hybrid-Cloud Infrastructure**

## Purpose

This document contains the literature survey conducted for the project.

The survey examines research related to:

- Predictive autoscaling
- Workload forecasting
- Kubernetes autoscaling
- Microservice-aware scaling
- Resource optimization
- Hybrid-cloud autoscaling
- Multi-cloud resource management
- SLO-aware resource management
- Cost-aware resource allocation
